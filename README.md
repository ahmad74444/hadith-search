# الباحث الحديثي

برنامج للبحث في الأحاديث النبوية الشريفة مع شرحها وتخريجها ودرجتها.

يستخدم واجهة wxPython متوافقة مع قارئ الشاشة NVDA.

## المميزات

- البحث في الأحاديث النبوية عبر موسوعة الأحاديث النبوية المترجمة
- عرض نص الحديث والراوي والدرجة والمصدر والشرح ومعاني الكلمات والفوائد
- متوافق مع قارئ الشاشة NVDA
- إمكانية فتح الحديث في الموقع مباشرة
- البحث عن التحديثات تلقائياً

## المتطلبات

- Python 3.8 أو أحدث
- wxPython

## التثبيت

```bash
pip install wxPython
```

## التشغيل

```bash
python hadith_search.py
```
